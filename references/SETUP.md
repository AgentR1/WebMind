# WebMind macOS / Codex: setup

Read the complete local [User Guide](../User%20Guide.md) and [Safety Instructions](../Safety%20Instructions.md).
Use the platform launcher contained in this edition. Do not install only a component.
The source folder stores only a selected-Mem pointer; the user chooses external memory.

初始化成功后，按 [Mem 初始化要求](../components/webmind-mem/GUIDE.md) 主动向用户介绍用户自己浏览器模式、Agent 专用浏览器模式和不可见模式。不可见模式只能使用 Agent 专用浏览器；每次任务未明确选择时默认不启用，不继承上次选择。

After initialization succeeds, follow the [Mem initialization requirements](../components/webmind-mem/GUIDE.md)
and actively explain user's own browser mode, dedicated Agent browser mode and invisible
mode. Invisible mode is available only for the dedicated Agent browser; it is off
unless explicitly selected for the current task and is not inherited from earlier tasks.
